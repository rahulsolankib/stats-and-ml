# Stats and ML Learning Journal

Welcome to my learning repository for statistics and machine learning. This repo is a place where I collect notes, experiments, examples, and projects that document my progress as I explore foundational concepts and build practical intuition.

## What’s inside

- A study folder dedicated to the Stats and ML concepts, including an interactive notebook and notes.
- `README.md` – This overview of the repo and its purpose.

## Goals

- Capture clear, hands-on explanations of statistical concepts.
- Track machine learning techniques, workflows, and model intuition.
- Keep a growing library of notebooks and notes that make learning easier to revisit.
- Build a personal reference that combines theory with examples.

## How to use this repo

- Explore folders named for topics or concepts.
- Open notebooks to review worked examples and visualizations.
- Add new learning notes, code, and experiment results as you go.

## Notes

This repo is best suited for:

- Students learning statistics and machine learning.
- Anyone who wants a structured way to document concept-by-concept progress.
- Self-study projects with notebooks, formulas, and example problems.
